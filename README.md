# 로봇 학습: 월드모델과 그 외 기술 동향 정리

## 1. 월드모델(World Model) 이란

**정의**: AI가 물리 세계의 법칙과 상호작용을 학습해, 행동에 따라 환경이 어떻게 변화할지 예측하는 내부 표현. "세상을 시뮬레이션할 수 있는 예측 모델"

**온전한 월드모델이 갖추어야 할 핵심 목표**
- 미래 예측 (다음 상태·관측 예측)
- 반사실적 추론 (대안 행동 시나리오 시뮬레이션)
- 물리 법칙·기하·접촉·동역학 이해
- 일반화 (한 번도 본 적 없는 환경에서도 예측)

**로봇 학습에서의 기능/역할**
1. **정책 학습 지원** — 상상된 궤적으로 정책 훈련
2. **계획(Planning)** — 모델 예측 제어(MPC), 행동 탐색
3. **시뮬레이터(Simulator)** — 가상 롤아웃으로 RL 평가·사후학습
4. **데이터 생성** — 부족한 로봇 데이터를 합성 데이터로 보강
5. **평가(Evaluation)** — 정책 성공/실패 예측

## 3. 월드모델 이외의 기술

### 3-1. 전통적 학습 방법
- **모방학습(Imitation Learning / Behavior Cloning)**: 인간 시연을 따라 학습. 데이터 확보 비용이 높고, 학습 범위 밖(out-of-distribution)에서 실패
- **강화학습(RL)**: 시행착오와 보상 기반. 샘플 효율이 낮아 실제 로봇 적용 어려움 → 시뮬레이션 결합 필요
- **보상 모델링(RLHF 계열)**: 비디오·언어로부터 작업 성공/보상을 추론

### 3-2. Sim-to-Real 계열
- **도메인 무작위화(Domain Randomization)**: 수천~수만 개의 변형 환경으로 과적합 방지, 현실 격차 극복
- **도메인 적응 / 디지털 트윈**: NVIDIA Isaac Sim, Gazebo 등 고충실도 시뮬레이터

### 3-3. 파운데이션 모델 계열 (현재 주류)
- **VLA(Vision-Language-Action)**: 비전+언어+행동 통합 정책. RT-2/RT-X, OpenVLA, Figure Helix
- **LLM 기반 태스크 플래닝**: 자연어로 작업 분해·계획 (SayCan, Code as Policies, PaLM)
- **로봇 파운데이션 모델(RFM)**: 대규모 데이터 사전학습으로 다양한 플랫폼·작업 일반화

### 3-4. 자기지도학습(SSL)
- **JEPA 계열** (V-JEPA 2, C-JEPA, LeCun): 라벨 없는 비디오로 물리 상식·세계 이해 학습. 월드모델의 대안이자 보완

| **한국 동향** | 현대로보틱스 H-Bot 플랫폼(모방+RL 하이브리드), K-로봇 2030 정책, 삼성·KAIST 협력 파운데이션 모델 개발 |

## 종합 요약

- 월드모델은 **시뮬레이션·계획·데이터 생성** 측면에서 중요해졌으며, 파운데이션 모델과 결합해 훈련 비용·시간을 획기적으로 줄이는 방향으로 진화
- 실제 정책 학습은 **VLA / 파운데이션 모델 · 강화학습 · 모방학습 · 자기지도학습이 결합된 하이브리드**로 수렴
- 핵심 과제: 대규모 로봇 데이터("로봇의 인터넷") 확보, 크로스-엠보디먼트 일반화, 안전성과 물리적 이해
